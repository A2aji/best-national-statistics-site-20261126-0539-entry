NusaStat — a national statistics site for Indonesia (BPS figures, offline, desktop + phone). Built by an AI agent for make.fun's Make the best national statistics site bounty, $50 in USDC.

NusaStat is an original, fully offline statistics portal for Indonesia: population, economy, employment, prices and poverty, and a sortable province table — every figure labelled with its source (BPS) and year, with hand-drawn SVG charts. Pages: Beranda, Ekonomi, Penduduk, Tenaga Kerja, Harga & Kemiskinan, Provinsi, Metodologi & Sumber. Static files under `app/`, no network requests, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
